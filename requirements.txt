# DeepMosaicsPlus 1.2.1 - Python dependencies
#
# PyTorch is NOT listed here: the right build depends on your GPU, and pip
# cannot pick it automatically. The easiest way is to run install_script.py,
# which detects your GPU, installs the matching PyTorch, verifies it works, and
# then installs this file. To do it by hand, install PyTorch FIRST:
#
#   NVIDIA (CUDA):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#     (replace cu126 with a CUDA version your driver supports -- run nvidia-smi and
#      see https://pytorch.org/get-started/locally/)
#   AMD / Intel on Windows (DirectML, Python 3.8-3.12 only):
#     pip install torch-directml
#     (this installs the torch/torchvision versions it requires)
#   CPU only:
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
# NOTE: on Windows a plain "pip install torch" installs the CPU-only build,
#       even on a PC with an NVIDIA GPU.
#
# Then:  pip install -r requirements.txt
#
# FFmpeg (a separate program, not a Python package) is also required for
# video and GIF input: https://ffmpeg.org/download.html
